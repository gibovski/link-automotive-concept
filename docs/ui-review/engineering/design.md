# Engineering concept

Classic British-car owners and drivers of other makes should be able to identify relevant work, understand the considerations behind a build, and call or get directions. Keep the authentic triangle, team caricature, Moorabbin location and visible unofficial notice. Treat user-provided services as enquiry topics and distinguish editorial imagery from workshop photos.

Desktop uses a split editorial hero, a compact make list, three-column service grid, project examples and a separate workshop contact panel. Mobile keeps the navigation visible and stacks the content in reading order. Borrow Bandcamp's direct action hierarchy and use WCAG 2.2 for visible focus and usable targets. Keep Barlow Condensed, warm ivory, near-black green, a vermilion accent and a restrained drafting grid. Use reduced-motion-aware scroll animation for the abstract hero field.

Primary journey: hero → service or project detail → contact → native phone or maps. Anchors work without scripting. The site has no submission, disabled or destructive states. Optional photos load progressively when a valid file is present and leave text or brand artwork in place on failure.
